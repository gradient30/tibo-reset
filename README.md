# Tibo Reset 追踪

追踪 Tibo（@thsottiaux）公布的 Codex / ChatGPT 用量重置：预测依据、预测时间、实际时间、间隔趋势。时间均为北京时间（UTC+8）。预测仅为估计，非官方。

在线访问：https://gradient30.github.io/tibo-reset/

## 更新
- `python3 build.py`：从 `radar.json` 重新计算数据并生成 `index.html`
- `python3 build.py render`：只用现有 `data.json` 重新渲染

数据源：Tibo 的 X 帖子、codex-reset.com（Radar）。
